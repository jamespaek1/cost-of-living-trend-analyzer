Data notes

Index values reflect a Numbeo 2026 snapshot (New York City = 100), with several U.S. city values as reported by source rankings; others are approximate. City prices change continuously, so treat this as a point-in-time comparison, not a live feed. The global side can be wired to Numbeo's API or the World Bank Open Data API — see the README.

When opened over the internet, country inflation is pulled live from the free World Bank Open Data API (latest available annual value); economies with no recent World Bank value — e.g. Venezuela, Iran — fall back to IMF World Economic Outlook (April 2026) forecasts. Purchasing power — expensive ≠ unaffordable

The same price tag bites harder on a smaller paycheck. This divides each city's average net wage by its cost of living, indexed to New York = 100. Higher means locals can buy more.

Income basis

strained → comfortable for locals
Data notes

Purchasing power = average net monthly wage ÷ cost-of-living index, rebased to New York = 100 — the same idea as Numbeo's Local Purchasing Power Index. Wage figures are approximate net-salary proxies; swap in Numbeo's API or World Bank GNI-per-capita (PPP) for live values. The point isn't the exact rank — it's the reframe: a city can top the cost charts yet stay livable on local wages.
